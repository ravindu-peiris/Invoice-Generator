# Ceylonova Booking Voucher Generator

A mobile-friendly static web app for generating Ceylonova Global Tours booking voucher PDFs.

## Features
- Auto-generated tour reference
- Automatic issue date
- Check-out calculated from check-in + duration
- Meal-basis and duration dropdowns
- Add/remove room types and quantities
- Automatic total room count
- One-click PDF download
- PDF file name equals the generated tour reference
- No database or server required

## Local preview
```bash
python -m http.server 4173
```
Then open http://localhost:4173
